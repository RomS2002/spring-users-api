# Spring Users API

Учебный проект для практики Java Backend на Spring Boot.

Цель проекта - последовательно изучить разработку REST API, работу со Spring Data JPA, тестирование (JUnit + Mockito), а также лучшие практики построения backend-приложений.

## Технологии

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Maven
- JUnit 5
- Mockito

## Планируемый функционал

- Получение списка пользователей
- Получение пользователя по ID
- Создание пользователя
- Обновление пользователя
- Удаление пользователя
- Валидация входных данных
- Глобальная обработка исключений
- Unit-тесты сервисов
- Тесты контроллеров
- Интеграционные тесты
